# 历史快照存储去重

范围：只调整独立 Atlas 的存储与读取。7 个历史版本的逻辑内容、原始字节、schema、来源、阅读记录、执行记录及已有 integrity 均保持；不修改产品代码，不创建新的历史版本。

## 设计与执行顺序

1. **记录基线**：保存 7 份原文件的字节长度和 SHA-256、产品文件摘要及历史网页资产摘要。现有相关测试先通过。
2. **先写失败检查**：验证精确还原与共享、混合格式、不可覆盖、损坏/缺块、路径及解压边界、迁移中断、恢复出口。
3. **独立存储层**：原 UTF-8 字节仅在根对象属性边界分块，不重新序列化。块按解压后字节的 SHA-256 定址并用 gzip 保存；每份 `snapshot.store.json` 有独立的有序引用、总长度与总摘要。没有跨版本父链，单个版本可独立还原。
4. **统一入口**：历史加载、全文审阅基线与新快照写入都经过存储层。先验证物理内容，再沿用原有快照语义校验。浏览器继续消费原来的完整对象，存储格式不进入阅读器。
5. **可恢复迁移**：原文件先留在 ignored 恢复目录；写入块、发布清单并核对完整还原后，才移除活动目录中的旧 JSON。允许旧/新格式混合；同 ID 双格式必须逐字节相同，冲突或损坏不能静默回退。
6. **验证与交付**：逐份还原 SHA 与原字节一致，历史网页投影摘要一致，v4 维护基线与 v5 全文审阅基线仍可用。运行 Atlas 检查、必要的执行回执复跑，以及历史阅读器核对。

## 约束

- 存储清单的摘要仅证明保存和还原一致，不为旧 schema 1 补签或提升证据等级。
- 不共享可变解析对象；块只复用不可变字节。
- 块名只由合法摘要构造；拒绝符号链接、路径越界、未知格式、大小不符、压缩损坏和解压超限。
- 发布完整清单前不改变当前版本指针；已有清单和块不可覆盖。中断时旧文件或已完整清单仍可读取。
- 本轮不加入自动垃圾回收。共享块的清理必须检查全部清单；恢复副本与临时检查输出均不提交。
- 不以修改旧回执摘要代替验证。新增读取模块纳入采集器输入，变化后的当前回执重新执行，历史回执原样还原。

## 基线与方案实测

原文件共 76,619,313 B。只读样本测得：逐份 gzip 约 11.26 MB；顶层原始字节分块为 118 次引用、76 个独立块，加 7 份清单约 6.57 MB。细分到嵌套数组会增加数千小文件，本轮采用顶层分块。

## 完成结果

- 7 个版本全部迁移，118 次块引用复用 76 个对象；清单与对象合计 **6,567,659 B**，原始 **76,619,313 B**，减少 **91.4%**，无未引用对象。
- 对比本轮入口原件与 SHA-256，7 份均逐字节相等；5 份 schema 1 和 2 份 schema 2 保持原等级及 integrity。`current.json` 未改变，未新增第 8 个历史版本。
- 浏览器历史资产的 7 组 URL、摘要和字节数与迁移前完全一致。实际逐份切换历史首页；v5 时序图在浏览器正常渲染，未新增 PNG。
- v5 基线的 53 文件全文复核命令通过；v6 原 JSON 通过真实 restore 命令导出，长度与入口 SHA 一致。同 ID 新快照命令仍拒绝覆盖。
- `npm run check` 通过：65 项 Node 检查、17 项 Vitest 检查、类型、lint、63 页当前证据、103 图既有渲染回执及构建。新存储覆盖缺块/损坏、原字节、并发、不可覆盖、路径/大小限制、中断与恢复；构建保留原有图形引擎大 chunk 提示。
- 采集器输入发生真实变化，已重新执行 **112 组、1379 项** Agent 定向断言，全部通过且输入稳定。历史执行回执未重写，没有用更新旧摘要代替执行。
- 样板只新增 `snapshot-store.mjs` 的 harness 输入，六场景断言和产品实现未改。已逐页确认 5 篇样板引用页的唯一输入变化是该列表，并更新其来源摘要；未修改正文或图源。
- 本轮入口的 **569 个产品文件**字节保持不变。恢复原件与过程日志只在 ignored `.cache/snapshot-storage-migration/`，不纳入提交。

## 维护边界

代码与文件级检查已在当前本地 Node 环境执行。存储依赖共享块，误删一个块可能影响多个版本；读取会明确拒绝损坏，不回退到另一版。目录与文件同步改善发布耐久性，但不声称多文件断电事务。并发迁移期间读者可能收到一次明确的读取失败，可在迁移结束后重新读取。

未请求 commit、push 或发布，所以未提交。后续维护使用 `snapshot:verify` / `snapshot:restore`；不要手工覆盖快照或按单个版本清理共享块。本轮未加入自动垃圾回收或新的产品需求。
